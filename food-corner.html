Implementation summary

Changes made to this website for the JavaScript Practical Assignment. All five required features are implemented directly inside this file.

No.JavaScript TaskWhere Implemented on the Site
1Form Validation"Book a table" section (id="booking"). Validates Name, Email, Mobile, Guests, and Booking Date.
2Dynamic GreetingHero section (id="home"). A badge above the heading shows a time-based greeting.
3Dynamic Bill / Price Calculation"Estimate your order" section (id="order"). Checkboxes for menu items update a running total.
4Show / Hide Content"Chef's special" section (id="special"). A "Read more / Read less" button toggles extended dish details.
5Dynamic Content / Image Change"Our Special Menu" section (id="menu"). A spotlight card with Previous/Next buttons cycles through 4 menu items.

1. Form Validation — Table Booking Form

Collects guest name, email, mobile number, number of guests, and booking date. JavaScript checks for empty fields, a letters-only name, a valid email pattern, a 10-digit mobile number, a guest count between 1 and 20, and a date that isn't in the past. Shows a success or error message and resets on success.

2. Dynamic Greeting

Reads the current hour with new Date().getHours() on page load and displays "Good Morning", "Good Afternoon", or "Good Evening" in a badge above the hero heading.

3. Dynamic Bill / Price Calculation

Pizza (₹250), Paneer Tikka (₹180), Veg Burger (₹120), and Cold Coffee (₹100) are selectable checkboxes. A "change" listener recalculates the total instantly as items are checked or unchecked.

4. Show / Hide Content

The Chef's Special card has a "Read more" button that toggles a hidden CSS class to reveal serving size, spice level, and pairing suggestions. The label switches between "Read more" and "Read less".

5. Dynamic Content / Image Change

A menu spotlight widget with Previous/Next buttons updates the displayed dish name, category, and icon, cycling through Pizza, Paneer Tikka, Veg Burger, and Cold Coffee.
