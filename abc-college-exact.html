Implementation summary

Changes made to this website for the JavaScript Practical Assignment. All five required features are implemented directly inside this file.

No.JavaScript TaskWhere Implemented on the Site
1Form Validation"Admission Enquiry" section. Validates Name, Email, Mobile, Age, and Preferred Counselling Date.
2Dynamic GreetingHero section. A badge above the heading shows a time-based greeting.
3Dynamic Bill / Price Calculation"Estimate Your Course Fee" section. Checkboxes for Tuition, Hostel, and Lab fees update a running total.
4Show / Hide Content"Course Spotlight" section. A "Read more / Read less" button toggles extended course details.
5Dynamic Content / Image Change"Our Courses" section. A spotlight widget with Previous/Next buttons cycles through all 4 courses.

1. Form Validation — Admission Enquiry Form

Collects applicant name, email, mobile number, age, and preferred counselling date. JavaScript checks for empty fields, a letters-only name, a valid email pattern, a 10-digit mobile number, an age between 15 and 60, and a date that isn't in the past. Shows a success or error message and resets on success.

2. Dynamic Greeting

Reads the current hour with new Date().getHours() on page load and displays "Good Morning", "Good Afternoon", or "Good Evening" in a badge above the hero heading.

3. Dynamic Bill / Price Calculation

Tuition Fee (₹45,000), Hostel Fee (₹8,000), and Lab & Library Fee (₹5,000) are selectable checkboxes. A "change" listener recalculates the total instantly as fees are checked or unchecked.

4. Show / Hide Content

The Course Spotlight card has a "Read more" button that toggles a hidden CSS class to reveal duration, eligibility, and career paths. The label switches between "Read more" and "Read less".

5. Dynamic Content / Image Change

A course spotlight widget with Previous/Next buttons updates the displayed course name, cycling through BCA, MCA, B.Tech CS, and M.Tech CS.
